# v0.10.6 Roadmap

## Scope

- Personal plugin usability and setup experience
- Architecture cleanup (workflow/report boundary, large file split)
- `portfolio_input.transactions` fallback
- Provider/NAV enhancement
- Report quality and valuation semantics
- Override schema validation with privacy-first design

## Non-goals

- No broker/order execution
- No auto trading
- No formal `Decision` from `fund_analysis`
- No marketplace publishing
- No live credential handling inside core
- No private data committed

## Workstreams

### WS1: Private data doctor / setup assistant
- Local doctor that checks `private_data/` readiness without exposing sensitive content
- Schema validation for identity overrides and NAV overrides
- Counts-only output, no real fund names / amounts / transaction IDs

### WS2: Workflow/report boundary cleanup
- Clarify `src/skills_runtime/` vs `src/tools/portfolio/report_sections/` responsibilities
- Remove dead code paths
- Ensure deterministic report section construction

### WS3: Large file split
- Break up oversized modules without changing behavior
- Preserve all existing test coverage

### WS4: Transaction source fallback
- `portfolio_input.transactions` fallback when no Alipay CSV is available
- Support manual transaction entry via template

### WS5: NAV/provider fallback
- Graceful degradation when provider data is unavailable
- Clear user-facing warnings about data gaps

### WS6: QDII/conversion/refund/fee refinement
- QDII fund handling (currency, settlement)
- Conversion and refund transaction types
- Fee attribution in cashflow summary

### WS7: Report semantics / golden tests
- Golden test coverage for A/B/C2/D2 scenarios
- Ensure `cashflow_only` / `estimated` / `valuation` / `none` labels are consistent
- No fake `0.00`, no misleading `reconstructed_from_ledger`

## Acceptance Criteria

- Private data remains local (never committed)
- Synthetic tests pass
- Real E2E remains desensitized
- v0.10.5 behavior remains compatible (A/B/C2/D2 semantics unchanged)
- New features behind clear inputs/options
- No degradation of existing gate results:
  - `test_fast`: 2338+ passed
  - `test_identity_nav`: 70+ passed
  - `test_plugin_smoke`: 236+ passed
  - Privacy check: PASS
  - Workflow/report/public_api/architecture: 438+ passed
